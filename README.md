# Estudio de soluciones para la coloración de grafos

En este repositorio tenemos el código correspondiente al proyecto de la materia CI5652 - Diseño de Algoritmos II, en el que elegimos un problema [NP-completo](https://es.wikipedia.org/wiki/NP-completo) para luego comparar la eficacia y eficiencia de distintas soluciones, principalmente heurísticas y metaheurísticas (que son el objetivo de esta materia).

En nuestro caso, elegimos la [coloración de grafos](https://es.wikipedia.org/wiki/Coloraci%C3%B3n_de_grafos), que es un problema que surge en muchas distintas áreas y contextos, y las soluciones a este problema son muy útiles.
